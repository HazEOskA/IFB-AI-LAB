# IFP DEEP RESEARCH — V0.2

**Mode:** research only.  
**No production changes. No new UI code in this slice.**

## 1. Executive finding

The Instytut Fundraisingu website is not just a brochure site. It already contains the raw material for a much stronger product ecosystem:

- personal expert brand around **Martyna Mazela**,
- consulting / implementation offers,
- two current live implementation programs,
- a WooCommerce catalogue with six paid products,
- a large archive of educational content,
- testimonials with unusually strong numerical outcomes,
- historic campaign case studies with real visual assets,
- a newsletter audience,
- and a growing AI layer already embedded in Martyna's current course offer.

The strongest positioning direction is:

> **IFP = Fundraising Operating System for NGOs**  
> Strategy + implementation + education + tools + AI execution layer.

The AI Lab should therefore not look like a detached chatbot product. It should feel like the newest execution layer of an existing fundraising methodology.

## 12. Research conclusion

The premium rebuild should not be structured as:

**homepage → services → about → contact**

It should communicate a connected operating system:

```
AUTHORITY
Martyna + proof
      ↓
METHODOLOGY
Strategy 4K / stable donations / campaign method
      ↓
PROGRAMS
live implementation journeys
      ↓
TOOLS
calculators / templates / products
      ↓
AI LAB
bounded execution layer
      ↓
CASE STUDIES
proof of real-world outcomes
      ↓
KNOWLEDGE
blog / ebooks / newsletter
```

This gives the redesign a much stronger strategic reason to exist than visual refresh alone.
