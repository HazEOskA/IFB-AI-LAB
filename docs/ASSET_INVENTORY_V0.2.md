## E. Asset quality rules for next build

1. Use Martyna's latest 2026 transparent portraits as priority assets.
2. Pull full-resolution originals from WordPress Media Library before production.
3. Keep campaign artwork because it proves real work.
4. Client logos should be normalized visually but not recolored in a way that alters brand identity.
5. Do not use AI-generated portraits of real people when real approved photos exist.
6. Use WebP/AVIF generated derivatives in production while preserving originals.
7. Never hotlink production assets permanently from the old site; migrate approved media into the new asset pipeline.
8. Keep alt text tied to actual person / organization / campaign.
